# Policies Reference

The `coba` system provides a comprehensive set of Multi-Armed Bandit (MAB) algorithms, from basic baselines to advanced non-linear meta-heuristics. Each algorithm is designed to solve specific challenges in Dynamic Pricing.

To keep documentation modular and easy to read, the detailed intuition, mathematical foundations, and standalone code examples for each policy have been separated into dedicated reference pages.

## Contextual Bandits

These are the primary algorithms used in most production setups. They analyze the current environment (e.g., weather, available drivers, time of day) via a context vector to predict the optimal price.

1. **[LinUCB (Linear Upper Confidence Bound)](algorithms/linucb.md)**
   A deterministic algorithm that uses an "exploration bonus" to encourage trying out new actions in unfamiliar contexts.

2. **[LinTS (Linear Thompson Sampling)](algorithms/lints.md)**
   A stochastic Bayesian algorithm. Often the best choice for production systems with delayed feedback or batch updates.

3. **[Logistic Bandits (Laplace Approximation)](algorithms/logistic.md)**
   Specifically designed to handle binary outcomes. The absolute best choice if your goal is to optimize **Conversion Rate**.

4. **[Meta-Heuristics (Tree-based & Scikit-learn Wrappers)](algorithms/sklearn_meta.md)**
   Wraps powerful machine learning estimators like **LightGBM** or **Random Forest** in Bandit exploration mechanisms (Bootstrapped, Epsilon Greedy) to tackle complex, non-linear market behaviors.

---

## Context-Free Bandits

These algorithms ignore the customer's context and rely purely on historical click/conversion data. They are the perfect, intelligent upgrade over traditional **A/B Testing**.

5. **[UCB1 & Thompson Sampling](algorithms/context_free.md)**
   Automatically funnels traffic toward the arm with the highest conversion rate as quickly as possible.

## Advanced Topics

To bring your Bandit system from the lab to a real-world production environment, you will likely need to solve three major challenges:

1. **[Cluster Routing](algorithms/cluster_router.md)**
   Tackle non-linear and unstable markets by automatically dividing your traffic into sub-clusters, each managed by an independent Bandit. Also provides native support for adding/removing arms at runtime (Warm Start).

2. **[Off-Policy Learning (IPS & Doubly-Robust)](algorithms/offpolicy_ips.md)**
   Bootstrap a brand new Bandit model from biased historical data generated by your old, legacy system. COBA uses Inverse Propensity Scoring to un-bias the logs.

3. **Multi-Objective Contextual Bandits (Scalarization)**
   If you need to optimize multiple business metrics simultaneously (e.g., maximizing GMV while keeping Conversion Rate above a certain threshold), the fastest and most stable approach in `coba` is **Reward Scalarization**.

Rather than writing a complex multi-objective policy that slows down the system, you simply define a composite reward function before calling `update()`:

```python
# Weights defined by business rules
w_gmv = 0.7
w_cr  = 0.3

# Normalize raw metrics to [0, 1]
normalized_gmv = actual_gmv / max_expected_gmv
is_converted   = 1.0 if user_booked else 0.0

# Single composite reward
composite_reward = (w_gmv * normalized_gmv) + (w_cr * is_converted)

bandit.update(context=context_vector, arm=chosen_arm, reward=composite_reward)
```
This keeps the core math engines running at maximum speed while leaving business logic entirely flexible on the outside.
